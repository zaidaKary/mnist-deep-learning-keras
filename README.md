Desarrollé un proyecto de clasificación de dígitos manuscritos MNIST usando redes neuronales en Keras/TensorFlow. Realicé preprocesamiento de datos (normalización, reshape y one-hot encoding), experimenté con hiperparámetros como número de neuronas, epochs, funciones de activación, estrategias de inicialización y optimizadores, implementé técnicas de regularización (Dropout, Batch Normalization, L2 y Early Stopping) para prevenir overfitting, y diseñé un modelo final de 5 capas que superó el 97% de precisión en validación.
